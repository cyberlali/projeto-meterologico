# App de Clima

Uma aplicação web para consultar a previsão do tempo e as condições meteorológicas de qualquer cidade em tempo real.

## 🚀 Funcionalidades

- **Pesquisa de Cidades:** Permite buscar o clima de qualquer cidade do mundo digitando o nome na barra de pesquisa.
- **Dados em Tempo Real:** Exibe informações exatas como a temperatura em graus Celsius (°C), a porcentagem de umidade e a velocidade do vento em km/h.
- **Ícones Dinâmicos:** O ícone principal do tempo se altera automaticamente com base nas condições atuais (nublado, céu limpo, chuva, chuvisco, neblina).
- **Tratamento de Erros:** Exibe uma mensagem amigável caso a cidade digitada não seja encontrada.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura da página, entradas de texto e organização dos elementos.
- **CSS3:** Estilização visual, definindo o layout em formato de cartão e as cores de fundo em gradiente.
- **JavaScript (Vanilla):** Lógica da aplicação integrada para consumo da API do OpenWeatherMap utilizando chamadas assíncronas (`fetch`).

## 📁 Estrutura de Arquivos

- `index.html`: Contém a estrutura principal e o script com a lógica de comunicação com a API.
- `style.css`: Arquivo com os estilos visuais e o layout do cartão da aplicação.

## 💻 Como Executar o Projeto

**1. Clone este repositório para o seu computador:**

`git clone https://github.com/cyberlali/projeto-meterologico.git`

**2. Acesse a pasta do projeto:**

`cd projeto-meterologico`

**3. Abra o projeto:**
Certifique-se de ter a pasta `images/` com os ícones necessários à aplicação. Depois, basta abrir o arquivo `index.html` no seu navegador web de preferência e testar o clima de qualquer cidade!
