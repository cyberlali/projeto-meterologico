# App de Clima

Uma aplicação web para consultar a previsão do tempo e as condições meteorológicas de qualquer cidade em tempo real, utilizando a API do OpenWeatherMap.

## 🚀 Funcionalidades

- **Pesquisa de Cidades:** Permite buscar o clima de qualquer cidade do mundo digitando o respetivo nome na barra de pesquisa.
- **Dados em Tempo Real:** Exibe informações exatas como a temperatura em graus Celsius (°C), a percentagem de humidade e a velocidade do vento em km/h[cite: 4].
- **Ícones Dinâmicos:** O ícone principal do tempo altera-se automaticamente com base nas condições atuais (nublado, céu limpo, chuva, chuvisco, nevoeiro)[cite: 4].
- **Tratamento de Erros:** Exibe uma mensagem de erro indicando que a cidade não foi encontrada caso o texto introduzido seja inválido[cite: 4].

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura da página, entradas de texto e organização dos elementos[cite: 4].
- **CSS3:** Estilização visual através do ficheiro `style_2.css`, definindo o layout e as cores de fundo em gradiente[cite: 5].
- **JavaScript (Vanilla):** Lógica da aplicação incorporada no HTML, responsável pela integração com a API externa utilizando a função `fetch` assíncrona[cite: 4].

## 📁 Estrutura de Ficheiros

- `index_2.html`: Contém a estrutura principal e o script com a lógica de comunicação com a API[cite: 4].
- `style_2.css`: Ficheiro com os estilos visuais e o layout do cartão da aplicação[cite: 5].
